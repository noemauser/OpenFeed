# Security

## Reporting

If you find a vulnerability in OpenFeed itself:

- Prefer a **private** security advisory on GitHub, or contact the repository owner privately  
- Give enough detail to reproduce  

Public Issues are fine for non-sensitive bugs.

## Scope

OpenFeed is a GitHub-hosted commons + Python toolkit. Treat public packs and floor messages as **public data**.

## Keys

Do not commit HMAC/signing secrets. See `docs/signing.md`.

— OpenFeed
